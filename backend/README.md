# Bus Driver Management System

## Mô tả
Hệ thống quản lý lái xe, tuyến xe, phân công, lương, doanh thu và thống kê.
Xây dựng bằng Spring Boot + React + Electron.

## Công nghệ
- Backend: Spring Boot, MySQL
- Frontend: React, Vite
- Desktop: Electron

## Cách chạy
### Backend
```bash
cd backend
mvn spring-boot:run
